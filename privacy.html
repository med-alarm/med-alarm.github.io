개인정보처리방침

복약 알리미 (med-alarm.github.io)

1. 요약

  • 이름·연락처·주민등록번호·처방 내용 등 개인정보를 받지 않습니다.
  • 카카오톡으로 알림을 등록할 때만, 카카오가 제공하는 회원번호와 일시적 접근 권한(토큰)을 등록 처리에 사용하고 즉시 폐기합니다. 저장하거나 기록하지 않습니다.
  • 쿠키·광고·방문 분석 도구를 쓰지 않습니다.

2. 처리하는 정보와 목적

알림 등록 화면약국이 정한 복용 방법(예: 아침·저녁, 30일)과 이용자가 고른 알림 시각만 사용합니다. 이 값은 휴대폰 안에서만 계산되며 서버로 보내지 않습니다.
카카오톡으로 알림 받기 항목: 카카오 회원번호, 카카오 접근 토큰, 알림 일정(시각·반복 횟수)
목적: 이용자 본인의 카카오톡 캘린더에 복약 알림(할 일)을 만드는 것
근거: 카카오 로그인 화면에서의 이용자 동의 (선택 항목: 톡캘린더 할 일 생성·조회·편집/삭제)
휴대폰 캘린더에 추가아이폰 캘린더는 휴대폰 안에서만 처리됩니다. 구글 캘린더를 고르면 구글의 일정 추가 화면으로 이동하며, 이후는 구글의 정책을 따릅니다.

알림 제목은 "약 복용 · 아침"처럼 복용 시간만 표시하며, 약 이름이나 질환은 넣지 않습니다. 이용자가 '알림 이름'(선택, 10자 이내)을 직접 입력한 경우에만 그 이름이 제목에 들어가며(예: "감기약 · 아침"), 이 값도 등록에만 쓰고 저장하지 않습니다.

3. 보유 기간과 파기

카카오 회원번호와 토큰은 알림 등록 요청을 처리하는 동안(수 초)만 서버 메모리에서 사용하고, 처리가 끝나면 토큰을 카카오에 만료 요청한 뒤 버립니다. 데이터베이스나 기록 파일에 남기지 않습니다.

만들어진 알림은 이용자의 카카오톡 캘린더에 저장되며 카카오가 관리합니다. 이 서비스는 그 알림을 따로 보관하지 않습니다.

4. 제3자 제공과 처리 위탁

개인정보를 제3자에게 제공하지 않습니다. 서비스 운영을 위해 다음 업체의 시설을 이용합니다.

GitHub (미국)알림 등록 화면 호스팅
Cloudflare (미국)카카오톡 등록 처리 서버 실행 — 요청 처리 중에만 위 정보가 거쳐 가며 저장하지 않음
카카오카카오 로그인 및 톡캘린더 (이용자 동의에 따라)

GitHub·Cloudflare 서버는 국외에 있을 수 있으며, 접속 시 각 업체가 보안을 위해 접속 기록을 처리할 수 있습니다.

5. 이용자의 권리

  • 알림 삭제: 카카오톡 → 캘린더 → 할 일에서 직접 지우면 됩니다. 반복 알림은 "이후 모든 할 일"을 고르면 한 번에 지워집니다.
  • 동의 철회(연결 끊기): 카카오톡 → 설정 → 카카오계정 → 연결된 서비스 관리 → 외부 서비스에서 이 서비스를 선택해 연결을 끊을 수 있습니다.
  • 이 서비스는 이용자 정보를 보관하지 않으므로, 열람·정정을 요청할 대상 정보가 없습니다.
